# TecovLLM ModelZoo

## 介绍

TecovLLM是深度适配太初AI加速卡的大模型推理框架。框架深度整合太初元碁底层驱动、运行时、计算库等核心组件，助力用户在太初AI加速卡上便捷高效地开展大模型推理业务。本框架完整兼容原生vLLM核心推理能力，同时结合太初AI加速卡硬件架构特性完成深度定制优化，涵盖算子融合、定制高性能算子、AI编译优化等多项技术手段，全方位提升大模型整体推理性能与运行效率。
TecovLLM-ModelZoo专注完成各类外部模型适配工作，统一存放模型适配代码，简化开发者模型接入流程，降低适配成本，方便快速调试与部署使用。
