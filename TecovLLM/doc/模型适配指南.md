# 模型推理适配指南

本文档介绍如何适配推理模型，使其能够在太初加速卡进行推理。整体流程如下：

1. 检查推理环境：使用Tecorgin ModelZoo进行推理适配前，检查Tecorgin ModelZoo的开发环境，确保您的开发环境能够充分满足当前任务需求。
2. 适配模型推理：对模型源码、推理相关接口等进行适配，使模型能够基于Tecorgin ModelZoo提供的环境进行推理。
3. (可选) 自定义算子开发与接入：如果模型迁移中存在SDAA不支持或者精度不达标的算子，可以进行算子开发，并将算子接入到TecoInferenceEngine框架。
4. 精度调试：如果适配后模型精度不达标，需要进行精度调试，确保其满足精度要求。
5. 性能调优：如果适配后的模型性能不达标，需要进行性能调优，确保其满足性能要求。
6. 添加Readme文件：基于适配的模型推理文件和代码，编写模型推理使用说明。
7. 提交PR：完成所有适配测试并通过后，将代码提交到Tecorigin ModelZoo仓库。

## 1. 检查推理环境

在使用Tecorgin ModelZoo进行推理适配之前，建议您先熟悉Tecorgin ModelZoo的开发环境配置，包括熟悉模型开发使用的框架、加速卡等硬件资源信息，以确保您的开发环境能够充分满足当前任务的需求，从而确保适配及推理过程的顺利进行。

本节介绍如何检查Tecorign ModelZoo的开发环境，包括硬件环境检查和容器环境检查。

## 2. 模型推理适配

### 2.1 适配前准备

适配前需要准备的内容如下：

1. 检查并确认源码、模型和数据集。
2. 适配标准。

#### 2.1.1 检查源码、模型和选取数据集

适配之前需要检查源码、模型和数据集，确保其满足适配要求。具体流程如下：

1. 根据以下源码优先级，选择合适的源码：太初指定的源码 > 官方源码 > 第三方开源 > 个人开源。
2. 明确适配模型的具体规格，例如：Qwen3需区分模型尺寸（如 7B/14B/32B）与模型类型（如LLM/VL），避免歧义。
3. 按模型类别选用适配测试数据集与评价指标，使用Evalscope对模型服务接口进行测试，并保证测试覆盖维度完整；以Omni全模态模型为例：需同时覆盖语言、多模态图文、语音三类数据集。

#### 2.1.2 适配标准

1. 基于EvalScope测试得到模型服务接口的数据集评测得分，与vLLM标准GPU环境下数据集评分绝对误差不超过0.05；若超出误差阈值，需注明具体原因，示例：评测样本量偏少、评分存在随机波动等。

##### 2.1.3.1 获取精度基线

1. 启动模型vLLM服务,启动命令可参考[vLLM用户手册](https://vllm.hyper.ai/docs/inference-and-serving/openai_compatible_server),或模型官方提供的vLLM启动命令。
2. 使用EvalScope测试数据集精度,测试命令可参考[EvalScope用户手册](https://evalscope.readthedocs.io/zh-cn/latest/get_started/supported_dataset/index.html)。

### 2.2 适配模型推理

适配模型推理的主要流程如下：

1. ModelZoo目录说明：Fork ModelZoo仓库并按规范新建模型文件。
2. 适配模型结构：若当前TecovLLM版本未内置待适配模型结构，需自行重新实现适配；若已原生支持，可直接复用现有模型结构，无需重复开发。
3. 模型接入TecovLLM：将完成适配的模型代码文件拷贝至环境中对应的TecovLLM模型目录，替换或新增模型文件后，启动TecovLLM推理服务验证模型加载、单样本请求及多轮推理功能是否正常。
4. 检查适配后的推理模型是否满足要求。

#### 2.2.1 ModelZoo目录说明

##### 2.2.1.1 创建目录

Tecorigin ModelZoo中`TecovLLM`目录是推理相关代码的工作目录。在您本地的Tecorigin ModelZoo仓库中，新建文件`{model_type}.py`，用于存放适配后的推理相关代码。其中：模型文件名称必须严格按照模型权重`config.json`配置文件中的 `model_type`参数值命名。

#### 2.2.2 适配模型结构

1. 若待适配模型已在当前vLLM版本中原生内置支持，可直接复用vLLM提供的官方模型结构与推理逻辑，无需重新开发模型代码；若存在算子不兼容情况，请通过PyTorch算子接入方式完成适配，具体接入步骤参见`3. 自定义算子开发与接入`。
2. 若待适配模型未被当前vLLM版本内置支持，需根据模型架构、网络结构、配置参数自行实现模型适配代码，完成模型结构定义、前向推理逻辑、权重加载等核心功能开发，保证模型可在vLLM框架中正常加载与推理。

##### 2.2.2.1 适配模型常见问题

模型适配过程中常出现算子接口不匹配、算子参数不兼容等问题，本节说明相关排查方法与标准解决方式。

1. 算子接口不匹配
2. 算子参数不支持
3. 算子缺失


#### 2.2.3 模型接入TecovLLM

1. 安装TecovLLM和vLLM whl包(如果直接给docker就不用)。
```
pip install ./TecovLLM/vllm_whl/vllm.whl
pip install ./TecovLLM/vllm_whl/tecovllm.whl
```
2. 定位TecovLLM包安装路径：在当前环境中执行查询命令`pip show vllm`，返回结果中的Location字段即为包所在根目录`{vllm-root}`。
3. 放置模型文件：将完成适配的模型代码，拷贝或替换到对应模型目录`{vllm-root}/vllm/model_executor/models/`下。
4. 验证推理功能：执行离线推理脚本，验证模型加载、多卡并行推理、单样本/多样本推理是否正常。离线推理脚本参考如下:
```
import os
os.environ["VLLM_USE_MODELSCOPE"]="True"
os.environ["SDAA_VISIBLE_DEVICES"]="0,1,2,3"

from vllm import LLM, SamplingParams

def main():
    # Create an LLM.
    llm = LLM(model="Qwen/Qwen3-0.6B",  # 此处请修改为模型权重实际路径
              max_num_seqs=32,
              max_model_len=8192,
              tensor_parallel_size=4)

    # Sample prompts.
    prompts = [
        "Hello, my name is",
        "The president of the United States is",
        "The capital of France is",
        "The future of AI is",
        "解释一下温故而知新的意思",
        "explain the meaning of 'rain cats and dogs'",
    ]
    # Create a sampling params object.
    sampling_params = SamplingParams(temperature=0, max_tokens=1024)

    # Generate texts from the prompts.
    # The output is a list of RequestOutput objects
    # that contain the prompt, generated text, and other information.
    outputs = llm.generate(prompts, sampling_params)
    # Print the outputs.
    print("\nGenerated Outputs:\n" + "-" * 60)
    for output in outputs:
        prompt = output.prompt
        generated_text = output.outputs[0].text
        print(f"Prompt:    {prompt!r}")
        print(f"Output:    {generated_text!r}")
        print("-" * 60)


if __name__ == "__main__":
    main()

```

## 3. 自定义算子开发与接入

如果模型迁移中存在SDAA不支持或者精度不达标的算子，可以进行算子开发，并将算子接入到PyTorch框架。

- 算子开发，请参考太初元碁官方文档[SDAA C编程指南](http://docs.tecorigin.net/release/sdaac/)。
- 算子接入TecoInferenceEngine框架，请参考太初元碁官方文档[xxxxxxx](http://docs.tecorigin.net/release/torch_2.4/v2.1.0/#6fb567bef4285602b1a1541a3828d14a)。
- 算子使用, 在模型代码中通过torch接口使用接入的算子。

## 4. 精度调试

模型适配后，如果精度不能满足需求，则需要进行精度异常原因分析和调优。具体方法可以参考太初元碁官方文档[精度调测](http://docs.tecorigin.net/release/tecoinferenceengine/#6261b8696b0055e8a16199a0aeeb3f62)进行解决。

## 5. 性能调优

模型适配后，如果训练性能不能满足需求，则需要进行性能分析和调优。具体方法可以参考太初元碁官方文档[性能调优](http://docs.tecorigin.net/release/tecoinferenceengine/#63ddfb2e68b756c19b91c94b0423334e)。
