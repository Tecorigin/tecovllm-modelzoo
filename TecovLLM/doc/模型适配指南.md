# 模型推理适配指南

本文档介绍如何适配推理模型，使其能够在太初加速卡进行推理。整体流程如下：

1. 检查推理环境：使用TecovLLM-ModelZoo进行推理适配前，检查TecovLLM-ModelZoo的开发环境，确保您的开发环境能够充分满足当前任务需求。
2. 适配模型推理：对模型源码、推理相关接口等进行适配，使模型能够基于TecovLLM-ModelZoo提供的环境进行推理。
3. (可选) 自定义算子开发与接入：如果模型迁移中存在SDAA不支持或者精度不达标的算子，可以进行算子开发，并将算子接入到TecovLLM框架。
4. 精度调试：如果适配后模型精度不达标，需要进行精度调试，确保其满足精度要求。
5. 性能调优：如果适配后的模型性能不达标，需要进行性能调优，确保其满足性能要求。
6. 添加Readme文件：基于适配的模型推理文件和代码，编写模型推理使用说明。
7. 提交PR：完成所有适配测试并通过后，将代码提交到TecovLLM-ModelZoo仓库。

## 1. 检查推理环境

在使用TecovLLM-ModelZoo进行推理适配之前，建议您先熟悉TecovLLM-ModelZoo的开发环境配置，包括熟悉模型开发使用的框架、加速卡等硬件资源信息，以确保您的开发环境能够充分满足当前任务的需求，从而确保适配及推理过程的顺利进行。

本节介绍如何检查TecovLLM-ModelZoo的开发环境，包括硬件环境检查和容器环境检查。

## 2. 模型适配

### 2.1 模型分析

适配前需完成以下确认，保障适配顺利开展：

1. 模型可运行验证：确认模型在CPU或GPU环境下能正常加载、完成基础推理，无报错或异常退出。
2. 量化标准确认：当前仅支持FP16、INT8两种量化格式，其他格式暂不兼容。
3. 并行策略确认：
   - TP（张量并行）：按硬件核组数配置，单卡为4核组，单卡运行时TP=4。
   - PP/DP/EP：并行规则与标准CUDA保持一致。

### 2.2 模型组网

使用`torch`和`torch_sdaa`相关算子和函数，实现模型的网络结构。具体实现方式和要求，请参考vLLM官网的[OPT模型适配](https://docs.vllm.ai/en/stable/contributing/model/basic/)示例。本文使用的Seed-OSS模型的网络结构实现代码，见[Seed-OSS网络结构](../models/Seed-OSS-36B-Instruct/seed_oss.py)。

### 2.3 模型注册

1. 安装TecovLLM和vLLM whl包(若环境中已安装则跳过该步骤)。
```
pip install ./TecovLLM/vllm_whl/vllm.whl
pip install ./TecovLLM/vllm_whl/tecovllm.whl
```
2. 定位TecovLLM包安装路径：在当前环境中执行查询命令`pip show vllm`，返回结果中的Location字段即为包所在根目录`{vllm-root}`。
3. 放置模型文件：将模型组网文件放在`{vllm-root}/vllm_sdaa/models/`目录下。
4. 注册模型到TecovLLM。在`{vllm-root}/vllm_sdaa/models/init.py`文件中，添加模型注册代码，将步骤一实现的模型，注册到Teco-vLLM中。注册代码如下：
```
def register_model():
    # 导入模块注册模型模块
    from vllm import ModelRegistry
    # 注册模型
    ModelRegistry.register_model(
        "SeedOssForCausalLM", "vllm_sdaa.models.seed_oss:SeedOssForCausalLM")
```
注：如有新增模型，直接在`register_model`函数内继续添加`ModelRegistry.register_model`语句即可。

### 2.4 运行模型

#### 2.4.1 离线推理
参考[离线推理](http://docs.tecorigin.com/release/teco_vllm/v3.1.0/#d6692347dc1c533ab3651f83213ae646)文档，完成模型离线推理验证。

#### 2.4.2 在线推理
参考[在线推理](http://docs.tecorigin.com/release/teco_vllm/v3.1.0/#43351f4b9e305913b221a171b0a5a59d)文档，完成模型在线推理验证。

## 3 算子开发

模型迁移过程中，若出现 SDAA 硬件暂不兼容算子或算子运算精度未达标准的情况，系统将触发对应算子异常报错。对此可通过定制开发适配算子，并完成算子适配接入，实现算子无缝集成至TecovLLM推理框架。算子开发并通过PyTorch框架接入算子，请参考太初元碁[算子开发仓库](https://github.com/Tecorigin/teco-ops)。

## 4 精度分析

适配过程中若出现模型精度不达标问题，可通过以下步骤完成精度分析与验证：
- 精度对比与分析工具：使用官方精度分析工具完成模型推理结果与基准数据的对比分析，定位精度差异来源。相关工具的使用方法请参考太初元碁官方文档[精度分析工具使用指南](xxx)。
- Evalscope数据集精度验证：使用Evalscope评测工具在标准数据集上对模型进行精度验证，确认模型在多任务场景下的整体精度表现。Evalscope评测的使用方法请参考官方文档[Evalscope模型评测指南](https://evalscope.readthedocs.io/zh-cn/latest/get_started/supported_dataset/index.html)

## 5 性能分析

为确保模型在 SDAA 平台上的运行效率，需完成以下性能测试、分析与调优工作：

1. 性能测试：通过EvalScope性能测试工具，对模型的吞吐、延迟、显存占用等关键指标进行基准测试，获取模型的基础性能数据。测试工具的使用方法请参考太初元碁官方文档[EvalScope性能测试工具](http://docs.tecorigin.com/release/teco_vllm/v3.1.0/#e468da21ea2151fdba18302f31212be7)。
2. 性能分析：使用性能分析工具，对模型运行过程中的算子耗时、通信开销等进行拆解分析，定位性能瓶颈。分析工具的使用方法请参考太初元碁官方文档 [性能分析工具使用说明](xxx)。
